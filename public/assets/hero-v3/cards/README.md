# Согласованные карточки

> Это runtime-копии, приглушённые для текущего hero. Master PNG, история генерации,
> промпты и QA находятся в [`design/orbit-cards/`](../../../../design/orbit-cards/)
> и описаны в [`docs/ORBIT_CARDS_EDITING.md`](../../../../docs/ORBIT_CARDS_EDITING.md).
> Не использовать эту папку как единственный источник для будущего редизайна.

В этой папке лежат только явно утверждённые пользователем финальные PNG. Файлы нумеруются по реестру из `docs/05_CARD_LIST.md`.

Не перезаписывать утверждённый файл без прямой команды пользователя. При повторном согласовании класть новую версию с суффиксом `-v2`, сохраняя предыдущую.
