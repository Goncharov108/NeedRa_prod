# NeedRa — продукт (истина для копирайта)

Версия: 0.1  
Язык интерфейса: русский

## Одна фраза

**NeedRa — аналитика Wildberries через одну строку чата с ИИ: спросил → получил таблицу или график → сохранил или скачал Excel.**

## Как устроено (внутри, не для hero)

```
WB API → сбор данных → база данных → ИИ-агент → ответ пользователю
```

Снаружи пользователь **не видит** десятки готовых дашбордов и сотни экранов. Он видит **чат**.

## Что умеет пользователь

| Действие | Описание |
|----------|----------|
| Задать вопрос | На русском, как коллеге: «маржа по SKU за неделю», «остатки по складам» |
| Получить вид | Таблица, график или комбинация — собирается под запрос |
| Сохранить маску | Повторяемый шаблон отчёта под свои задачи |
| Дополнить маску | Расширить сохранённый вид новыми полями или срезами |
| Скачать Excel | Выгрузить результат для бухгалтерии, команды, себя |

## УТП (рабочая формулировка)

- **Простота:** один интерфейс вместо зоопарка вкладок.
- **Гибкость:** не фиксированный дашборд — отчёт под ваш вопрос.
- **Скорость:** данные уже в системе; не нужно вручную собирать отчёт из пяти сервисов.

## Для кого (приоритет сообщений)

### 1. Селлер
Боль: много сервисов, много экранов, мало времени на «сборку ответа».  
Выгода: ответ за минуту, без обучения новому BI.

### 2. Менеджер / агентство
Боль: несколько кабинетов, разные форматы отчётов у клиентов.  
Выгода: маски отчётов, повторяемость, Excel на выход.

### 3. Новичок
Боль: не понимает, куда смотреть в аналитике.  
Выгода: спросить по-русски, получить понятный вид.

## Что НЕ обещаем на лендинге

- Гарантированный рост продаж или прибыли.
- «Лучше всех конкурентов» без имени и сравнения.
- Выдуманные цифры клиентов, отзывы, рейтинги.
- Полную замену бухгалтерии или юридической отчётности.

## Конкурентный контекст (для внутреннего use)

Типичный паттерн рынка: много таблиц, графиков и модулей «на все случаи».  
NeedRa: **данные те же по смыслу (WB), интерфейс — диалог.**

## Технические якоря (для FAQ, не для hero)

- Данные поступают через API Wildberries.
- Хранение в БД — для быстрых ответов агента.
- ИИ собирает представление (view), а не отдаёт сырой SQL пользователю.
