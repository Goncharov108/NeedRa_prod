# NeedRa — голос бренда (COPY_VOICE)

Версия: 0.1

## Философия

**NeedRa = Обмен**

- **Need** — потребность, конкретный вопрос селлера.
- **Ra** — обмен, цикл, поток данных и решений.

Мы говорим о **замыкании цикла**: спросил → получил → сохранил → выгрузил.
