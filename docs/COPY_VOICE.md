# NeedRa — голос бренда (COPY_VOICE)

Версия: 0.2

## Философия

**NeedRa = Обмен**

- **Need** — потребность, конкретный вопрос селлера.
- **Ra** — обмен, цикл, поток данных и решений.

Мы говорим о **замыкании цикла**: спросил → получил → сохранил → выгрузил.

## Запрещённые клише (AI-copy)

Не использовать без крайней необходимости:

- Elevate, Seamless, Unleash, Next-Gen, Revolutionize  
- «Революционный», «уникальный алгоритм», «на кончиках пальцев»  
- «Трансформация бизнеса», «квантовый скачок»  
- «Лучшее решение на рынке» без доказательства
