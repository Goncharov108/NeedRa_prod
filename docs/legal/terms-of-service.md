## 3. Условия предоставления Сервиса

### 3.1. Бесплатный объём

- **Первая загрузка** данных из API Wildberries — **бесплатно**.
- **Общение с ИИ-агентом** по загруженному снимку данных — **бесплатно** в рамках доступного функционала на момент использования (Исполнитель вправе вводить разумные технические лимиты против злоупотреблений).

### 3.2. Платная подписка

- **Ежедневное обновление данных** — **5 000 (пять тысяч) рублей в месяц**.
- Без активной подписки данные **не обновляются** автоматически на следующие сутки; сохраняется состояние на момент последней загрузки.
- Оплата и возвраты — по [Публичной оферте](./public-offer.md).

### 3.3. Индивидуальные метрики

По желанию Пользователь может указать себестоимость, систему налогообложения и иные параметры для более точных расчётов. Ответственность за корректность введённых метрик несёт Пользователь.
