## 3. Условия предоставления Сервиса

### 3.1. Бесплатный объём

- **Первая загрузка** данных магазина из API (Wildberries или Ozon) — **бесплатно** (после подключения кабинета в личном кабинете).
- **Общение с ИИ-агентом** по загруженному снимку данных — **бесплатно** в рамках доступного функционала на момент использования (Исполнитель вправе вводить разумные технические лимиты против злоупотреблений).

### 3.2. Платная подписка

Подписка оформляется **за каждый магазин** (кабинет маркетплейса) отдельно. Тариф одного магазина не покрывает другой.

- **Стандарт** — **5 000 (пять тысяч) рублей** за магазин в календарный месяц.
- **Pro** — **20 000 (двадцать тысяч) рублей** за магазин в календарный месяц (расширенные лимиты документов и глубины хранения — по оферте).
- Пример: Wildberries + Ozon на тарифе «Стандарт» — **5 000 + 5 000 ₽** в месяц.
- Без активной подписки данные **этого магазина** **не обновляются** автоматически на следующие сутки; сохраняется состояние на момент последней загрузки.
- Оплата и возвраты — по [Публичной оферте](./public-offer.md).

### 3.3. Индивидуальные метрики

По желанию Пользователь может указать себестоимость, систему налогообложения и иные параметры для более точных расчётов. Ответственность за корректность введённых метрик несёт Пользователь.
